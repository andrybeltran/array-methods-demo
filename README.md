# Array Lab: JavaScript Array Methods

An interactive beginner-friendly guide to JavaScript array mutator and accessor methods. Try the live examples, then open `index.html` to see how each method works.

**Live website:** [Array Lab](https://andrybeltran.github.io/array-methods-demo/)

**Repository:** [andrybeltran/array-methods-demo](https://github.com/andrybeltran/array-methods-demo)

## What the site demonstrates

### Mutator methods
Mutators change the original array.

- `push()` adds `"Fig"` to `fruitArray`.
- `splice(1, 1)` removes one item from `subjectArray` at index 1.

### Accessor methods
Accessors return new arrays and leave their source arrays unchanged.

- `slice(1, 4)` copies a range from `originalColors` into `slicedColors`.
- `concat(["Git"])` combines `baseTools` with another array into `allTools`.

Use the reset button to restore the mutator examples.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript with no dependencies.
